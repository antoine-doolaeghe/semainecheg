# 🎨 Architecture du Système de Cookies Persistants

## 📊 Vue d'Ensemble

```
┌─────────────────────────────────────────────────────────────────┐
│                      APPLICATION SEMAINECHEF                     │
│                         (React + TypeScript)                     │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                          App.tsx                                 │
│  • Gère l'état de l'application                                 │
│  • Appelle PersistentStorage.set/get                            │
│  • Affiche StorageDebugger (dev only)                           │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                    PersistentStorage                             │
│                  (cookieService.ts)                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌──────────────────┐         ┌──────────────────┐             │
│  │   .set(key, val) │         │   .get(key)      │             │
│  └────────┬─────────┘         └────────┬─────────┘             │
│           │                             │                       │
│           ▼                             ▼                       │
│  ┌─────────────────────────────────────────────┐               │
│  │      Tentative Cookies d'abord              │               │
│  │      ↓                                       │               │
│  │   ✅ Succès → Sauvegarde aussi localStorage │               │
│  │   ❌ Échec  → Utilise localStorage seul     │               │
│  └─────────────────────────────────────────────┘               │
│                                                                  │
└────────────────────────────┬────────────────────────────────────┘
                             │
              ┌──────────────┴──────────────┐
              ▼                             ▼
┌──────────────────────────┐   ┌──────────────────────────┐
│       COOKIES            │   │     localStorage         │
│   (Priorité)             │   │     (Backup)             │
├──────────────────────────┤   ├──────────────────────────┤
│ • Persistance : 10 ans   │   │ • Persistance : variable │
│ • Capacité : ~200 KB     │   │ • Capacité : 5-10 MB     │
│ • Survit au cache clear  │   │ • Effacé avec cache      │
│ • Fragmentation auto     │   │ • Toujours en backup     │
└──────────────────────────┘   └──────────────────────────┘
```

## 📦 Stack Technique

```
┌────────────────────────────────────────────────────────────────┐
│                      COUCHE APPLICATION                         │
│  React 19 + TypeScript + Vite                                  │
└──────────────────────────┬─────────────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────────────┐
│                    COUCHE PERSISTANCE                           │
│  PersistentStorage (cookieService.ts)                          │
│  • setCookie / getCookie                                        │
│  • Fragmentation automatique                                    │
│  • Fallback localStorage                                        │
└──────────────────────────┬─────────────────────────────────────┘
                           │
            ┌──────────────┴──────────────┐
            │                             │
┌───────────▼─────────────┐   ┌───────────▼─────────────┐
│    COOKIES              │   │    localStorage         │
│    (Browser API)        │   │    (Browser API)        │
│  • Max 50 cookies       │   │  • 5-10 MB              │
│  • ~4KB par cookie      │   │  • String storage       │
│  • 10 ans persistance   │   │  • Variable persistance │
└─────────────────────────┘   └─────────────────────────┘
```
